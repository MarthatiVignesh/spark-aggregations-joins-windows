# Spark Aggregations, Joins & Windows

A hands-on Apache Spark project using Scala to demonstrate DataFrame aggregations, joins, window functions, and Spark execution plans.

## Topics Covered

- Simple aggregations: `sum`, `avg`, `min`, `max`, `count`
- Grouping and aggregation by product and customer
- Inner joins between customers and orders
- Aggregation after joins
- Window functions for running totals
- Window ranking with `row_number`
- Extended Spark execution plans using `explain(true)`
- A final exercise combining JOIN + GROUPING + WINDOW

## Run

From the project directory:

```bash
sbt compile
sbt "runMain AggregationsJoinsWindows"
```

The program creates small in-memory DataFrames, so no external input data is required.

## Main Examples

### 1. Sales Aggregation

The first example calculates total, average, minimum, maximum, and order count, then groups the data by product and customer.

### 2. Window Functions

A running total is calculated for each customer. A ranking window ranks each customer's orders by amount.

### 3. Joins

Customer and order DataFrames are joined using `customer_id`. The joined data is then aggregated to calculate customer spending.

### 4. Execution Plan

`explain(true)` displays the parsed, analyzed, optimized, and physical plans generated by Spark's Catalyst optimizer.

### 5. Final Exercise

The final section combines an inner join, customer-level window aggregation, and per-customer order ranking.
